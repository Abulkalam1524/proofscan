ProofScan

Scanners guess. ProofScan proves.

A web vulnerability scanner that tests every suspicious finding before it reports it, and keeps the evidence.

The problem

Security scanners report a lot of things that are not real. Someone then has to check every alert by hand, which is the slow part of a security test. ProofScan does that checking itself. It looks for SQL injection and cross-site scripting (XSS), and every candidate gets a second, active test that tries to prove it. Only what it can prove goes in the report.

How it proves things

True/false test

Send an always-true and an always-false condition that differ in nothing else. If the pages differ by more than the page differs from itself, the database ran our input.

Timing test

For pages that never change. Two inputs, a sleep behind a true or a false condition. Confirmed only if the true side is slower every single time.

Real browser

Load the page in headless Chromium. The script has to hand back a random token only it knows. Coming back in the page is not enough, it has to run.

Verify mode: checking ZAP's own findings

ProofScan can also take ZAP's report and prove or reject each finding in it. ZAP keeps its wide coverage, and ProofScan adds certainty to the part it can test. ZAP's report only names the page and the input, so ProofScan rebuilds each request by reading the form on that page, then runs the same tests.

The case that shows the idea

On DVWA's CSP page our input comes back in the page completely unescaped. ZAP reports it as XSS, High risk. But the page sends a Content-Security-Policy header, so the browser refuses to run the script. ProofScan opened it in a real browser, five payloads ran zero times, and it threw the finding out. Reading the response cannot tell "came back" from "ran". Running it can.

Safe by design

  • Only scans hosts on an allow-list, with a rate limit on every request.
  • Never submits a form with two password boxes. During the benchmark ZAP did, and changed DVWA's admin password.
  • The web interface refuses anything that is not on the same machine, under the IT Act 2000.
  • This site only replays saved scans of test apps on my own laptop. It cannot scan anything.
